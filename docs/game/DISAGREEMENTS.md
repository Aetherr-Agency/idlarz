# Disagreements: old docs and comments against the code

Method: every statement of docs 02, 03, 07, 09, 10, 11, 24 and section 8 of doc 20 that states a rule, number or status was compared with the code (the files named in [docs/game](overview.md)). This list holds what is **wrong or stale today** (A), and what looks like a **bug or inconsistency in the code** (B). Nothing here was changed in the old docs or the code.

Not diffed: UI descriptions (docs 02 §12, §14, the controls in §16) were not checked against the components; docs 06 and 19 were out of scope (doc 26 already says their castle timer tables are old). "Plan, not built" lines (docs 10 perk families and monster chests, 20 relics and bands) are not errors; they are in [ROADMAP-COMPARE.md](ROADMAP-COMPARE.md).

Severity: **H** = a reader would build or balance on a wrong number; **M** = wrong but unlikely to mislead; **L** = wording or naming.
